# ecg-interpatient-benchmark
Reproducible benchmark for ECG arrhythmia classification on the MIT-BIH database using a lightweight 1D-CNN. Implements patient-wise and beat-wise evaluation, AAMI classes, DS1/DS2 split, hyperparameter tuning, bootstrap statistics, Grad-CAM explainability, efficiency analysis, and comparisons with ResNet, RR features, and random forest.
